# UD3D

UnKnownDevelopment C++ OpenGL 3D Framework

[GLAD]: OpenGL Graphics
<br>
[GLFW]: Window & Input
<br>
[GLM]: Math
<br>
[SimpleLogs]: Logs
<br>
[STB]: Image
<br>
[OPEN-AL]: Audio
<br>
[SOL]: Lua Scripting
<br>
[IMGUI]: Editor
<br>
[ASSIMP]: Model Loading

[Features]:
* Window Creation
* Camera Creation
* Default Shape Creation
* Model Loading With Assimp
* Lua Scripting -> OnStart, OnUpdate, OnShutdown Currently
* Textures
* Audio System
* Scene Manager, Config Manager, UI Manager For Orginization
